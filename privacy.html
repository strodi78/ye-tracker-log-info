Privacy notice

This notice describes the local Ye Tracker Log application and this public information website.

What the local application reads

  • Public Ye Tracker spreadsheet content for detecting and displaying changes.
  • If the user connects Google: read-only file metadata and file edit activity for that spreadsheet, including timestamps, Google-reported editor IDs, and the last modifying user’s exposed display name.
  • Google profile display names and profile photos when exposed by Google, to attempt identity resolution. The app does not read the user’s contact list.
  • If the user separately installs the optional browser companion: the participant names, avatars, status and anonymous count exposed in that tracker’s Google user interface. It does not identify anonymous participants or read Google authentication cookies.

Purpose and attribution

Information is used to monitor tracker changes, show local history and provide editor context. File-level activity and participant presence do not prove cell-level authorship. Uncertain attribution is labeled as an inference or left “Unknown.”

Storage

Tracker history and Google activity are stored in separate local SQLite databases on the user’s computer. Google client credentials and the offline login token are encrypted using Windows current-user protection. The token enables background read-only access after the user approves Google consent.

The application does not upload these databases or login tokens to this website. The original OAuth client JSON downloaded by the user remains wherever the user saved it until the user removes it.

Sharing

API requests go to Google to retrieve the configured tracker’s activity, metadata and exposed profile information. If the user enables Discord notifications, change descriptions and available editor context are sent to that user-configured Discord webhook. The optional browser companion reports to the local application. Tracker history and Google tokens are not sent to the website.

Google user data is not sold, used for advertising or transferred for unrelated purposes. Data obtained through Google APIs is used in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Local tracker history is durable. The activity reader keeps a rolling recent activity window, caches identity lookups, and stores per-event attribution results separately. Local data remains on the computer until the user deletes the corresponding local files. Freshness indicators expire after a failed or overdue read.

Users can stop the application, disconnect the optional companion, disable Discord, or revoke the Google connection in their Google Account connections. Deleting the local Google credential files prevents the application from refreshing its Google login. Revocation and local deletion do not erase messages already delivered to Discord.

This website

This site provides static application and privacy information. It has no application sign-in, forms, tracker database or application analytics scripts. The hosting provider may process connection and access information according to its own privacy policy.

Contact

For privacy questions, use the developer support email shown on Ye Tracker Log’s Google consent screen.
