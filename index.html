App information

Ye Tracker Log

A local application that monitors the public Ye Tracker Google spreadsheet, records changes in local history, and can send change notifications to a Discord webhook configured by its user.

Google connection

The optional read-only Google connection reads this tracker’s file activity and metadata. It can work without an open spreadsheet browser tab. Google’s basic profile permission is used to attempt to resolve Google-reported editor IDs into display names.

The Google permissions can cover files accessible to the signed-in account; the application’s reader is limited to the Ye Tracker spreadsheet. It does not edit the spreadsheet or read contacts.

Editor context

Google’s file activity does not include changed cell addresses or values. A reported file editor is context, not proof of a particular change’s author. When timing and identity evidence supports an inference, the app labels it “Likely editor.” Ambiguous or unavailable attribution remains “Unknown.”

Local operation

The watcher, its history, and the Google activity reader run on the user’s computer. This information website does not host the watcher, offer Google sign-in, or receive tracker history or Google login credentials.

For support, use the developer support email shown on the application’s Google consent screen. Read the privacy notice.
